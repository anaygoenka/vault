## Description

Vault remembers everything you copy, so you never lose a link, a paragraph or a colour again.

Press ⇧⌘V anywhere and a glass panel opens over whatever you are doing. Type a few letters to find any clip, see it in full, then press Return to copy it back. Press ⌘V and it is pasted.

EVERYTHING YOU COPY
• Text, links, images, files and colours, each with its own preview
• Colours you copy as HEX, RGB or HSL appear as swatches, ready to re-copy in any format
• Code is shown in a monospaced font, so it reads properly

FIND IT IN A SECOND
• Search across everything as you type
• Filter by text, links, images, files, colours or pinned
• Jump straight to recent clips with ⌘1 to ⌘9

YOU ARE IN CONTROL
• Choose how long history is kept: an hour, a day, a week, a month, three months, a year or forever
• Pin the clips you use every day; pinned clips are never deleted
• Copy as plain text to drop the formatting

PRIVATE BY DESIGN
• Your history never leaves your Mac. No accounts, no analytics, no network access
• Passwords and one-time codes from password managers are skipped automatically
• Exclude any app, or pause recording with one click

MADE FOR macOS
• Built in SwiftUI with Liquid Glass
• Lives in the menu bar, launches at login if you like, and stays out of your way
• Works entirely from the keyboard

Vault is open source: github.com/anaygoenka/vault

## Notes for App Review

Vault is a clipboard history app. It runs in the menu bar (no Dock icon).

To try it: copy a few things in any app, then press Shift-Command-V. Choose a clip with the arrow keys and press Return; Vault copies it to the clipboard and closes, then press Command-V to paste. Settings are in the menu bar icon.

Vault is sandboxed, requests no permissions, collects no data and makes no network connections. The global shortcut uses RegisterEventHotKey.
